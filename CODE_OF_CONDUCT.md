# Code of Conduct

This project follows the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** — the standard code of conduct used widely across open-source projects.

The canonical text (pledge, standards, enforcement responsibilities, scope, enforcement guidelines, and attribution) lives at the link above. We adopt it in full rather than inlining it here, so that any future updates from the Contributor Covenant maintainers automatically apply.

## Reporting

Instances of behavior covered by the Covenant — whether you experienced it or observed it — may be reported confidentially to the project maintainers at:

**conduct@goodtiming.ai**

All reports will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and safety of the reporter.

## Scope

This Code of Conduct applies within all project spaces — issues, pull requests, discussions, documentation, code review, the project's mailing list (if/when one exists), and any official project communication channel — as well as when an individual is officially representing the project in public spaces.
